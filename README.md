# 🛒 Amazon Homepage Clone

A frontend recreation of the Amazon homepage built using **HTML and CSS**.  
This project was created to practice frontend development concepts such as **Flexbox, layouts, navigation bars, background images, product cards, and responsive UI design**.

> ⚠️ **Disclaimer:** This project is made for educational purposes only. It is not affiliated with, endorsed by, or connected to Amazon.



## ✨ Features

- 🧭 Amazon-style navigation bar
- 📍 Location and delivery section
- 🔎 Search bar with category selector
- 👤 Sign-in and account section
- 📦 Orders & Returns section
- 🛒 Shopping cart section
- 🎯 Navigation panel with quick links
- 🖼️ Large hero/banner section
- 🛍️ Product/category cards
- 📱 Clean and structured frontend layout
- 🔻 Amazon-style footer
- ⬆️ Back-to-top section

## 🛠️ Technologies Used

- **HTML5** — Page structure and semantic elements
- **CSS3** — Styling and layout
- **Flexbox** — Navigation and card layouts
- **CSS Background Images** — Hero and product sections
